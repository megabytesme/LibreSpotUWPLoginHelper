**LibreSpotUWP Login Helper** is a helper utility which allows for easy sign in for the LibreSpotUWP app using a QR code. It is intended for older devices which cannot complete Spotify sign-in directly.

The helper now authorizes both Spotify library access and playback. Spotify may open twice during sign-in; use the same Spotify account both times. The generated QR code or exported text contains sensitive, temporary sign-in details, so only import it on devices you own.

**Disclaimer:** LibreSpotUWP is an unofficial, third-party implementation of a Spotify client for the Universal Windows Platform (UWP). This project is not affiliated with, endorsed, or sponsored by Spotify AB. Spotify is a trademark of Spotify AB.
